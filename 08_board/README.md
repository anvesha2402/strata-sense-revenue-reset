# 08 Board presentation and CEO memo (D8)

Strata Sense Technologies is a fictional company; all data are synthetic, built for an MBA capstone.

- `D8_Board_Deck.pptx`: 10-slide board deck — the ask, the problem, the plan, ARR delivery, execution, risks, Q1–Q2 FY27 triggers, limits, the close
- `D8_CEO_Memo.docx`: one-page CEO memo
- `D8_QA_Sheet.docx`: prepared answers to the five executive challenges (CFO, CMO, CPO, CRO, CEO)
- `code/`: `deck.js` builds the board deck (pptxgenjs, reads `fig/`); `memo.js` builds the CEO memo (docx)
- `fig/`: chart PNGs used in the deck, carried over from D7

AI use: deck, memo and drafting were produced with an AI assistant (Claude); every figure traces back to D7's model output.
