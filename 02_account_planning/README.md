# 02 Account planning and lead generation (D2)

Strata Sense Technologies is a fictional company; all data are synthetic, built for an MBA capstone.

- `D2_Account_Planning_Deck.pptx`: 12 slides with speaker notes
- `D2_Tiering_Coverage_Workbook.xlsx`: scoring back-test, 3,100-account tiering, coverage/capacity model, lead-gen funnel, budget reallocation, checks (live formulas; blue cells are inputs)
- `D2_Account_Plans.docx`: three strategic account plans (expansion, Helix displacement, new-logo whitespace)
- `code/`: `d2_score.py` (score + tiers, needs D1 outputs), `d2_capacity.py` (AE supply), `d2_workbook.py`, `deck.js`, `plans.js`

AI use: analysis code and drafting were produced with an AI assistant (Claude); every figure is reproducible from the code and data room.
